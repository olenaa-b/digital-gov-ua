# digital.gov.ua

Статичний сайт «Цифрова Вінниця» — каталог офіційних електронних сервісів Вінницької міської територіальної громади.

На сторінці зібрані посилання на транспортні, медичні, освітні та адміністративні сервіси, онлайн-запити, інструменти громадської участі, правничу допомогу, відкриті дані, міські мапи, сервіси безпеки, підтримки бізнесу та муніципальний застосунок MISTO.
