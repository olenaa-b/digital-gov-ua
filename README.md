# digital.gov.ua

Статичний сайт «Цифрова Вінниця» — каталог офіційних електронних сервісів Вінницької міської територіальної громади.

На сторінці зібрані посилання на транспортні, медичні та адміністративні сервіси, інструменти громадської участі, Геопортал, Портал відкритих даних, Цілодобову варту 1560 і муніципальний застосунок MISTO.
