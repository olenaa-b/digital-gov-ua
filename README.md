# digital.gov.ua

Мінімальний статичний лендінг «Цифрова Вінниця» для публікації через Cloudflare Pages.

## Cloudflare Pages

- Framework preset: None
- Build command: `exit 0`
- Build output directory: `/`

Після успішного розгортання спочатку перевірте адресу `*.pages.dev`, а потім підключайте `digital.gov.ua` як Custom domain.
